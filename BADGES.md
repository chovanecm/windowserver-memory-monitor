# Badges for README.md

Once you publish to GitHub, you can add these badges to the top of your README.md for a more professional look.

## Suggested Badges

Add these after the `# WindowServer Memory Monitor` title:

```markdown
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![macOS](https://img.shields.io/badge/macOS-10.14+-blue.svg)](https://www.apple.com/macos/)
[![Python](https://img.shields.io/badge/Python-3.6+-green.svg)](https://www.python.org/)
[![GitHub release](https://img.shields.io/github/v/release/YOUR_USERNAME/mac-windowserver-memleak-workaround.svg)](https://github.com/YOUR_USERNAME/mac-windowserver-memleak-workaround/releases)
[![GitHub stars](https://img.shields.io/github/stars/YOUR_USERNAME/mac-windowserver-memleak-workaround.svg?style=social)](https://github.com/YOUR_USERNAME/mac-windowserver-memleak-workaround)
```
